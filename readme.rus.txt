
 Горячие клавиши
 =============================
 Esc или Q ................... Выход
 Пробел ...................... Старт / Пауза
 C ........................... Переключиться между монохромным и цветным режимом отображения клеток (в цветном режиме цвет клетки зависит от ее возраста)
 R ........................... Перезапуск
 N ........................... Сделать один шаг вперед (только в режиме паузы)
 F ........................... Развернуть на полный экран / свернуть
 Колесо мыши ................. Увеличить / уменьшить скорость
